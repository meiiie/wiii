# Neko UI icons

This folder owns the semantic icon vocabulary used by Wiii and Neko Chill.

- Icons are inline SVG components from the repository's pinned `lucide-react` dependency.
- The wrapper fixes a consistent optical stroke and keeps icons compatible with `currentColor`.
- Product code asks for a semantic kind (`read`, `terminal`, `reasoning`, and so on), not a vendor icon name.
- State is communicated by nearby accessible text as well as color; glyphs are decorative by default.
- Brand character belongs in the Neko mark and illustrations. Functional controls stay quiet and literal.

Visual research lives in `artifacts/brand/icon-research/`; generated moodboards are references, not shipped UI assets.
