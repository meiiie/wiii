07 — Return

The last point of light is the first.

Built by The Wiii Lab.

The core product is AGPL-3.0-only. A separate commercial license is available. Code under sdk/ is Apache-2.0. These licenses do not grant rights to the Wiii name or branding.

The latest published release is Wiii 1.3.0, Windows x64, explicitly unsigned, tag wiii-v1.3.0. It includes the installer, a SHA-256 sidecar, and a release manifest. Linux and macOS do not have a public installer in this release. Checksums verify downloaded bytes, not publisher identity.

Neko Core is installed and configured separately. A version number in the repository is not, by itself, a release.

Choose a project folder and configure the model through Neko Core. Conversations stay with that folder.

A local project does not require a Wiii Service account. Vietnamese is the primary interface language.

Neko Core is the default. If Neko is unavailable, Wiii does not silently substitute another agent.

A missing harness is not a failed check. Look in Tổng quan → Quản lý harness.

Taking control cancels Wiii-owned queued input and waits. It does not undo an email already sent.

Computer is optional and experimental. Only granted project folders belong in it.
