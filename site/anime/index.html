Choose a project folder and configure the model through Neko Core. Conversations stay with that folder. Files, changes, browser, terminal, and the optional Computer sit beside the conversation. A local project does not require a Wiii Service account. Model providers may require their own account. Vietnamese is the primary interface language.

06 — Ma 間

Observation is not control.

An outcome you cannot see is not a success.

Taking control waits. It does not undo what already left.

Taking control cancels Wiii-owned queued input and waits for active input and held-key cleanup before the handoff. It does not undo an email already sent, and it does not stop every independent program inside the desktop. Unconfirmed cleanup stays blocked.

Computer is a persistent Linux desktop through Docker Desktop, with its own browser profile. Your host profile is not copied. It is optional, experimental, and a same-user workstation. Only explicitly granted project folders belong in it.
