# Wiii — The battle

A long-scroll battle for [Wiii](https://github.com/meiiie/wiii), served at
[anime.holilihu.online](https://anime.holilihu.online/). Wiii fights Drift.
The product web app keeps `wiii.holilihu.online`. The art direction is in
[ART_DIRECTION.md](ART_DIRECTION.md). Deploy steps are in [DEPLOY.md](DEPLOY.md).

```bash
npm ci
npm run dev
```

The Neko marks in `public/brand/` are copies of the approved files in
`docs/assets/brand/neko-family-v1/logo/`. Do not redraw them here. If the
canonical SVGs change, copy them again.

Nothing in this folder is imported by the desktop app or the service.
